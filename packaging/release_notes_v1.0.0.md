# 美股期权策略推荐器 v1.0.0

首个 Windows 安装包发布。

## 📥 安装说明

- **支持系统**:Windows 10 及以上(64 位)
- **一键安装**:双击下载的 `USOptionsAdvisor-Setup-1.0.0-win64.exe`,按中文向导点「下一步」即可,无需管理员权限、无需安装 Python
- **启动**:安装完成双击桌面图标,浏览器自动打开操作界面;关闭控制台窗口即停止服务
- **联网要求**:启动后行情来自 CBOE 延迟接口(免费无需 key);可选配置 Longbridge(长桥)账户读取真实持仓

## ✨ 功能亮点

- 📊 真实行情数据:CBOE 官方延迟行情,含期权链、隐含波动率、希腊字母
- 🧠 中长期策略全覆盖:LEAPS、价差、备兑、CSP、领口、铁鹰、铁蝶等,四象限分类
- 💰 自动接入 Longbridge(长桥)账户:一键带入真实持仓、美元现金、券商一致目标价、财报日历
- 🤖 AI 白话解读:把「持仓 × 目标价 × 财报窗口 × 资金占用 × 策略收益」讲成人话
- 🔐 页面内「连接设置」:API Key 直连 / OAuth 账号授权(支持一键动态注册),零环境变量配置
